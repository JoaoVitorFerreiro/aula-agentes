PRIMEIRO, O TERRENO

Antes de começar

Vamos conferir o que o grupo precisa para trabalhar sem tropeços.

+

O resultado deve mostrar a versão instalada. Node 18 ou superior? Pode seguir.

!

Escolha uma das opções para instalar. A primeira funciona em qualquer sistema com Node.

07

ESPECIALISTA COM REGRAS

Criar seu agente

Um agente é um arquivo .md de texto puro: nele você define quem ele é, o que faz e como deve trabalhar.

01

Copie agentes/_modelo_agente.md para agentes/agent_java.md.

02

Preencha identidade, objetivo, regras e etapas de trabalho.

03

Registre o nome e o caminho do arquivo em opencode.json.

04

Reabra o OpenCode e chame @agent_java ou use Tab.

EXEMPLO · AGENTE JAVA

O arquivo descreve o comportamento
agentes/agent_java.md
Você é o agent_java, especialista em Java.

## Objetivo
Criar classes e regras de negócio em Java.

## Regras
- Use Java 17+.
- Respeite a estrutura existente do projeto.
- Não altere arquivos fora do escopo combinado.

## Como trabalhar
1. Explique o plano antes de codar.
2. Faça uma mudança pequena por vez.
3. Liste os arquivos alterados.
IDENTIDADE

Quem é e em qual assunto ajuda.

LIMITES

Tecnologias, pastas e alterações permitidas.

PROCESSO

Como deve conduzir e encerrar o trabalho.

REGISTRAR NO OPENCODE.JSON

O cadastro conecta agente, modelo e arquivo
DENTRO DE "agent"
"agent_java": {
  "description": "Cria classes e regras de negócio em Java",
  "mode": "all",
  "model": "openai/gpt-6-luna",
  "prompt": "{file:./agentes/agent_java.md}"
}
!

Se houver outro agente antes deste, separe os blocos com vírgula. Não deixe vírgula depois do último. Os arquivos de agente são texto puro, sem cabeçalho de metadados.
